# n8n Workflow Planning Prompt

Use this prompt to plan an n8n workflow before building.

## Prompt

You are helping me design an n8n workflow.

Workflow goal:
[describe goal]

Trigger:
[describe trigger]

Inputs:
[list inputs]

Expected outputs:
[list outputs]

Systems involved:
[list systems]

Please produce:
1. workflow summary
2. step-by-step workflow design
3. node list
4. review checklist
5. possible improvements

Keep the design simple, reusable, and easy to review.
