# n8n AI Automation Roadmap (OGAX System)

## Overview

This repository is an AI-native automation engineering learning system and portfolio hub designed to guide learners from absolute beginner to advanced practitioner in building real-world automation systems using n8n, APIs, Git/GitHub, and AI agents.

It is not just a collection of examples — it is a structured engineering knowledge system combining:

- AI automation (n8n + AI agents)
- API integration engineering
- Git & GitHub workflow mastery
- Prompt engineering systems
- Real-world business automation
- Low-code / no-code architecture
- Workflow design thinking
- AI-native development systems

---

## Mission

To build a structured, practical, and production-aware learning ecosystem that transforms beginners into job-ready AI automation engineers capable of designing and deploying real-world workflows and automation systems.

---

## Core Technologies

- n8n (Workflow Automation)
- Git & GitHub (Version Control / GitOps)
- JavaScript (Automation logic)
- Python (Data processing)
- JSON (Workflow structure)
- REST APIs (System integration)
- AI Tools (OpenAI / LLM systems)

---

## Repository Structure

docs/        → Core learning (Git, n8n, APIs, AI fundamentals)
workflows/   → Real-world automation systems
prompts/     → AI prompt engineering + agent systems
examples/    → Code samples (JS, Python, JSON, APIs)
roadmap/     → Structured beginner → senior learning path
assets/      → Diagrams, architecture visuals
templates/   → Reusable automation structures
resources/   → Curated learning materials (courses, communities)
