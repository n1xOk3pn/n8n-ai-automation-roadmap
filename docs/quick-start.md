# Quick Start

## Purpose

Use this guide when starting a new n8n automation idea.

## Start Here

1. Define the workflow goal.
2. Identify the trigger.
3. List the input data.
4. List the expected output.
5. Identify the systems involved.
6. Sketch the workflow steps.
7. Build the smallest working version.
8. Review and document notes.

## Starter Questions

- What problem does this workflow solve?
- Who uses the output?
- What starts the workflow?
- What should happen when it succeeds?
- What should happen when it fails?
- What can be reused later?

## Output

End with a workflow brief before building.
