# Reuse Guide

## Purpose

This guide explains how to reuse this repository for n8n workflow planning and automation design.

## Workflow

1. Define the business problem.
2. Write the workflow goal.
3. List trigger, inputs, outputs, and systems.
4. Design the workflow steps.
5. Build a small version first.
6. Review and improve.
7. Document maintenance notes.

## Repository Areas

- `docs/` stores standards and guides.
- `templates/` stores reusable planning files.
- `workflows/` stores generic workflow examples.
- `prompts/` stores AI prompt patterns.
- `examples/` stores sample references.

## Review Checklist

- Goal is clear.
- Scope is controlled.
- Inputs and outputs are documented.
- Failure cases are considered.
- Notes are reusable.
