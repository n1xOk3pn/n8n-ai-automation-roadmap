# n8n AI Automation Roadmap — Agent Instructions

## Repository Identity

This repository is a reusable operating system for n8n automation learning, workflow design, API integration, and AI-assisted automation delivery.

It is public-reference safe. Do not add private, employer, or client-confidential information.

## Agent Role

AI agents may help create documentation, workflow plans, prompt templates, checklists, and examples.

AI agents may not invent client requirements, expose secrets, or create production workflows without review.

## Allowed Work

- Improve documentation
- Create reusable templates
- Draft workflow designs
- Create example workflows without credentials
- Improve testing and handover standards
- Review for maintainability and security

## Blocked Work

- Commit API keys, tokens, credentials, or exported secrets
- Add employer or client data
- Add real production webhook URLs
- Claim workflows are production-ready without testing
- Mix unrelated automation projects in one change

## Standard Workflow Document Requirements

Every workflow document should define:

- Objective
- Trigger
- Inputs
- Outputs
- Systems involved
- Workflow steps
- Error handling
- Credential strategy
- Testing plan
- Maintenance notes
- Risks

## Review Standard

Before reuse, check:

- Scope is clear
- No secrets are present
- Inputs and outputs are documented
- Errors and retries are considered
- Workflow is understandable by another operator
- Public repo safety is preserved

## Prime Directive

Make this repository easier to reuse, safer to reference, and more useful for real automation work.
